# mazetick-data

Derivado publicado do [mazetick.com](https://mazetick.com). Gerado no `bspnode`
por `build_site_data.py` quatro vezes ao dia e consumido pelo build do site.

⚠️ **Só derivado nosso entra aqui.** O recorte acontece na origem, por lista de
permissão, campo a campo — nenhum payload de fornecedor viaja. Publicar o nosso
cálculo é permitido; expor o dado de terceiro é revenda.

**Público por decisão:** a máquina de build da Cloudflare precisa buscá-lo sem
credencial.

⚠️ **Não empurre daqui sem que o `bspnode` saiba.** Ele tem o próprio clone. Em
2026-09-16 um push de outra cópia deixou o publicador quatro execuções
rejeitado, e o site serviu dado de 23h atrás. O script agora sincroniza antes de
publicar, mas o caminho barato continua sendo: escreveu aqui, avise lá.
